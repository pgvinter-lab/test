# Harmonia 1.0

Standalone Android app for adjusting high-stress couple communication through the ChatGPT, Claude, or Gemini consumer app already installed on the phone.

This build uses no model API, API key, Codex, or paid inference. It stores profile data locally, prepares the adjustment prompt, hands it to the selected AI app using Android sharing, accepts the AI response through Share Back, and opens the phone's messaging app only after the sender reviews the final text.
